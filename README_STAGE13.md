# Этап 13: слова без диагональных переходов

## Изменения

- Все 80 действующих уровней (`assets/levels.json`, по 20 на мир) перестроены для переходов только по горизонтали и вертикали. Повороты под прямым углом сохранены. ID, размеры, порядок и тексты целевых слов не менялись.
- Выбор пальцем, мышью и последовательными нажатиями использует правило четырёх соседей. Подсветка по-прежнему показывает фактический путь игрока.
- До нахождения слова показана первая буква и `?` вместо остальных, например `П?????? — 7 букв`. Найденное или открытое подсказкой слово отображается полностью.
- Прежние поля сохранены в `output_stage13/pre_orthogonal_levels.json`. Локальные сохранения автоматически переводятся на новые поля. Завершённые уровни, статистика, кристаллы и подсказки остаются; для уже найденного слова со старым несовместимым путём подсветка заменяется его новым допустимым каноническим путём. Награды за миграцию не начисляются.

## Данные и проверка

Перестройка воспроизводима с seed `20261011`; инструмент выбирает один из 32 кандидатов на уровень, штрафуя избыточные повороты. Отчёт: `output_stage13/report.json`. Независимый валидатор проверил **80 из 80** уровней: точное покрытие поля, буквы, отсутствие пересечений и повторных клеток, четыре направления, уникальность ID и полей, а также сохранность наборов слов. Во всех мирах по 20 уровней, суммарно 710 уникальных слов. Редакторская оценка удобства и качества слов остаётся отдельной задачей.

```powershell
python -m tools.rebuild_orthogonal output_stage13/pre_orthogonal_levels.json output_stage13/rebuilt

flutter analyze

flutter build web

```

Исторические результаты этапов 2–5 и их генераторы сохранены для сравнения. Они допускают диагонали и не являются источником действующих игровых полей.
