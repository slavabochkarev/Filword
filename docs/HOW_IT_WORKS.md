# ПоискСлов: как работает игра

В приложении четыре мира по 20 экспериментальных уровней: Город 7×7, Космос 8×8, Природа 9×9 и Наука 10×10. Поле каждого уровня полностью покрыто целевыми словами. Планируемые 400 окончательных уровней ещё не подготовлены.

## Выбор слова

Игрок может провести пальцем или мышью либо последовательно нажимать буквы. Следующая клетка должна быть соседней **по горизонтали или вертикали**. Повороты под прямым углом допустимы; диагональные шаги запрещены. Одну клетку нельзя использовать дважды в одном выборе. Нажатие на последнюю клетку ничего не меняет, на предпоследнюю — отменяет последний шаг. Поле остаётся неподвижным; прокручивается только список слов.

Игра принимает любой допустимый путь, который складывается в ещё не найденное целевое слово. Слово засчитывается автоматически. Подсвечивается фактический путь игрока, и его клетки можно снова использовать при поиске других слов. Записанные в JSON пути нужны для проверки уровня и подсказки с начальной буквой; они не навязываются игроку.

В списке до нахождения показывается первая буква слова и вопросительные знаки вместо остальных, например `П?????? — 7 букв`. Найденное слово раскрывается и зачёркивается. Платная подсказка может показать старт одного допустимого пути или открыть всё слово, но не засчитывает его.

После нахождения всех слов показывается экран победы. Двадцатый уровень завершает круг мира; следующий круг начинается с первого уровня. История прохождений, статистика, достижения и кристаллы сохраняются.

## Сохранение

`lib/progress_store.dart` сохраняет локально прогресс каждого мира, активное время, статистику, кристаллы, подсказки и найденные слова незавершённого уровня. При переходе со старых полей с диагоналями сохраняются завершённые уровни и найденные слова. Если фактический путь из старого поля неприменим в новом, для ранее найденного слова записывается его новый допустимый канонический путь. Повторного начисления награды при миграции нет.

## Данные и проверка

Игровой JSON — `assets/levels.json`. Все 80 полей перестроены из прежних наборов слов инструментом `tools/rebuild_orthogonal.py`; старые поля сохранены в `output_stage13/pre_orthogonal_levels.json`. Независимый валидатор `tools/validator_orthogonal.py` проверяет четыре направления, буквы, непрерывность и покрытие без пересечений. Исторические генераторы и результаты ранних этапов оставлены для сравнения. Подробнее о словах и источниках — в [WORDS_AND_LEVELS.md](WORDS_AND_LEVELS.md).

```powershell
python -m tools.validator_orthogonal assets/levels.json --original output_stage13/pre_orthogonal_levels.json
python -m unittest discover -s tests
flutter analyze
flutter test
```
