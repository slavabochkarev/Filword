# Филворд: как работает прототип

Актуально для этапа 6. В приложении находятся **20 тестовых уровней**: по пять для каждого мира. Планируемые 400 уровней ещё не подготовлены. Это описание относится к текущему коду, а не к будущей версии игры.

## Что видит игрок

На главной странице можно выбрать мир: Неон-Сити (7×7), Космос (8×8), Биосфера (9×9) или Киберядро (10×10). Все четыре мира доступны сразу. Карточка мира показывает следующий непройденный тестовый уровень; если пройдены все пять, для повторной игры открывается последний. Есть страницы темы, статистики, достижений и информации.

В игровом экране квадратное поле, счётчик и нижние кнопки закреплены. Прокручивается только список слов. Ненайденные слова стоят первыми; найденные переходят в конец списка в порядке нахождения. Размер клеток рассчитывается по `gridSize` и доступному месту. Перезапуск уровня очищает текущую игровую сессию.

## Как выбирается слово

Можно вести пальцем или мышью либо нажимать клетки по одной. Следующую клетку разрешено брать из восьми соседних, включая диагонали. Повороты разрешены. Повторное касание последней клетки ничего не меняет; возврат на предпоследнюю убирает один шаг. Остальные повторные и несоседние клетки игнорируются. Для быстрого движения указателя промежуточные точки линии проверяются, чтобы не пропускать узкие клетки.

После каждого добавленного шага игра сравнивает собранные буквы с ещё не найденными целями. Совпадение засчитывается сразу. Если короткое целевое слово является началом более длинного ещё не найденного слова, автоматический зачёт откладывается: можно продолжить длинное слово либо нажать «Завершить короткое слово». В нынешних 20 уровнях таких пар нет. При отпускании проведённого жеста незачтённый выбор проверяется и очищается; при последовательных нажатиях выбор сохраняется до совпадения или кнопки «Сбросить выбор».

Для зачёта не требуется идти по заранее записанному пути. Подходит **любой** непрерывный путь, который складывается в целевое слово, без повторного посещения клетки внутри одного выбора. Уже найденное слово второй раз не засчитывается. Клетки найденных слов можно снова использовать в других словах. Игра сохраняет и подсвечивает **фактический путь игрока**; более поздняя подсветка рисуется поверх ранней там, где они пересекаются. Записанные в JSON пути нужны для построения и проверки поля; игроку их не подменяют.

Когда найдены все слова, игра сохраняет результат и показывает экран поздравления с миром, номером уровня и количеством слов. Оттуда можно вернуться на главную или открыть следующий тестовый уровень того же мира. После пятого уровня игра сообщает, что следующих тестовых уровней пока нет.

## Что происходит внутри

1. `lib/main.dart` читает `assets/levels.json` и локальные настройки/результаты.
2. `lib/game_session.dart` хранит уровень, проверяет соседство, текст выбранного пути и однократный зачёт слова. Для старых уровней 10×10 без `gridSize` размер определяется по числу строк.
3. `lib/game_screen.dart` обрабатывает касания и мышь, рисует текущее выделение и найденные пути, обновляет список слов.
4. `lib/app_pages.dart` содержит главное меню, вспомогательные страницы и поздравление.
5. `lib/progress_store.dart` записывает результат через `shared_preferences`.

Генерация в приложении не выполняется: Flutter загружает готовый JSON. Формат и подготовка данных описаны в [WORDS_AND_LEVELS.md](WORDS_AND_LEVELS.md).

## Сохранение и статистика

Локально хранятся ID завершённых уровней, количество слов в завершённых уровнях, суммарное и лучшее время завершения, выбранная светлая/тёмная тема. Повторное прохождение уже завершённого уровня не прибавляет его слова и время к статистике. Достижения вычисляются из списка пройденных уровней. **Частичное прохождение не сохраняется**: после перезапуска незавершённый уровень начинается заново, а фактические пути подсветки восстанавливаются только в рамках текущей сессии. Аккаунта и сервера нет.

Из `C:\Project\Filword`:

```powershell
flutter pub get
flutter run -d chrome
flutter devices
flutter run -d <android-device-id>
flutter test
flutter analyze
python -m unittest discover -s tests -v
```

Тесты проверяют правила пути, оба способа ввода, автоматический зачёт, порядок слов, завершение и восстановление сохранённого результата. Проверка тестами не заменяет оценку удобства пальцем на реальном телефоне. Скриншоты этапа 6 находятся в `screenshots/stage6_*`.
