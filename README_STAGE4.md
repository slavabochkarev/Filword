# Филворд — этап 4: минимальный Flutter-прототип

Проект содержит один игровой экран для проверки управления полем 10×10. Десять уровней (ID 1, 4, 16, 101, 104, 201, 204, 301, 304, 316) скопированы из `output_stage3/candidates.json` без перегенерации. Их канонические пути остаются в JSON и используются тестами; найденный в игре путь всегда берётся из жеста игрока.

## Запуск

Из `C:\Project\Filword`:

```powershell
flutter pub get
flutter run -d chrome
flutter run -d <android-device-id>
flutter test
flutter analyze
```

Сборки: `flutter build web` и `flutter build apk --debug`. Доступные устройства: `flutter devices`.

## Управление

Нажмите на первую букву и ведите палец или мышь по соседним клеткам. Можно идти по диагонали и менять направление. Возврат на предыдущую клетку отменяет последний шаг. После отпускания засчитывается только слово из списка; повторный поиск не увеличивает счётчик. Уже подсвеченные клетки доступны для новых слов. При пересечении позже найденное слово рисуется поверх предыдущего. Кнопки снизу сбрасывают текущий уровень и переходят к следующему тестовому уровню.

## Файлы

- `lib/game_session.dart` — независимые модели уровня и правила зачёта.
- `lib/main.dart` — единственный экран, жесты и отрисовка.
- `assets/levels.json` — 10 неизменённых уровней этапа 3.
- `test/fixtures/alternative_examples.json` — примеры альтернативных путей этапа 3.
- `test/` — автоматические проверки модели, жестов и ширины экрана.
- `screenshots/` — снимки 360, 390, 412 логических пикселей и пример найденного альтернативного пути.

## Границы прототипа

Нет сохранения прогресса и остальных экранов. Реальное удобство жеста на телефоне требует отдельного ручного теста на устройстве: автоматические тесты проверяют правила и геометрию, но не точность пальца. Поле, счётчик и кнопки закреплены; на небольшом по высоте экране прокручивается только список слов.
