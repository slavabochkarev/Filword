# ПоискСлов — интеграция визуального дизайна

Flutter-приложение использует 20 существующих тестовых уровней из `assets/levels.json`. Python-генератор, исходные изображения в `DOC` и прежние результаты не изменены.

## Изображения

- `DOC/load.png` → `assets/images/splash.png`: полноэкранная заставка без искусственной задержки.
- `DOC/game.png` → `assets/images/home_hero.png`: фрагмент городского фона с логотипом; нарисованные элементы управления не используются.
- `DOC/razdels.png` → четыре отдельные иллюстрации в `assets/images/`: `city.png`, `space.png`, `nature.png`, `science.png`.

Названия миров, прогресс и области нажатия карточек созданы во Flutter. Сейчас все четыре мира доступны; карточка без уровней показывает сообщение вместо перехода.

## Навигация

Заставка показывается во время загрузки JSON и локального прогресса. Затем открывается главный экран. «Меню» открывает боковую панель с настройками, темой, статистикой, достижениями и информационными страницами. Выбор мира открывает его первый незавершённый уровень. После победы можно открыть следующий тестовый уровень или вернуться на главную.

Игровое ядро и фактическая подсветка пути игрока сохранены. Поле неподвижно; прокручивается только список слов. Прогресс завершённых уровней и тема сохраняются локально. Найденные слова незавершённого уровня пока не сохраняются — это отдельная задача до публичного выпуска.

## Перед публикацией

Политика конфиденциальности, соглашение и адрес обратной связи в меню пока обозначены как места для заполнения. Также нужны редакторская проверка слов, финальные уровни, собственный Android application ID, ключ подписи и проверка на реальном устройстве.
