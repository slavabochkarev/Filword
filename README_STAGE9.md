# ПоискСлов: новая заставка и фоны четырёх миров

## Ресурсы

Актуальный исходник заставки — `DOC/SplashScreen.png`, 941×1672. На нём находятся логотип «ПОИСКСЛОВ», кот, «ЗАГРУЗКА...» и светящаяся лапа. Исходник сохранён.

Для экранов 360×800, 390×844 и 412×915 подготовлен `assets/images/splash_screen.png`: встроенный imagegen использовал исходник как референс и разместил важные элементы дальше от боковых краёв. Исходное изображение не заменялось. Итоговый файл имеет размер 941×1672. Запрос к imagegen: сохранить логотип, кота, текст загрузки и лапу, расширить безопасные поля по бокам неба и города без новых элементов интерфейса. В SplashScreen используется только этот файл с `BoxFit.cover` и выравниванием по центру; Flutter не рисует поверх него текст или индикатор. Скриншоты трёх размеров подтверждают, что важные элементы видны полностью.

Фоны игры берутся из уже подготовленных независимых ресурсов 384×510. Каждый получен из `DOC/razdels.png` в предыдущем этапе:

| worldId в JSON | Мир | Фон |
|---|---|---|
| `neon_city` | Город | `assets/images/city.png` |
| `cosmos` | Космос | `assets/images/space.png` |
| `biosphere` | Природа | `assets/images/nature.png` |
| `cybercore` | Наука | `assets/images/science.png` |

## Поведение

После первого кадра заставки одновременно идут загрузка данных и ожидание двух секунд. Главная страница открывается, когда завершились оба процесса. Ожидание асинхронное. Заставка находится только в корневом состоянии до инициализации; при возврате из игры она не появляется. При новом запуске приложения создаётся новое состояние и заставка показывается снова.

Карусель передаёт список уровней выбранного мира в приложение. Приложение передаёт стабильный `worldId` выбранного уровня в GameScreen. Соответствие ID и фона хранится в `world_game_background.dart`. На следующих уровнях того же мира сохраняется тот же ресурс. Изображение находится позади игрового интерфейса, рисуется через `BoxFit.cover` и не перехватывает указатель. Подложки под счётчиком, подсказкой и кнопками дают контраст; сам фон остаётся виден. Игровое поле закреплено, прокручивается только список слов.

## Ограничения

Подключённого Android-устройства для ручной проверки жестов и первого кадра нет. Android проверен сборкой и Flutter-тестами с touch-событиями. Web собран, но ручную проверку в браузере остановил инструмент управления окном. Фоны миров имеют исходное разрешение 384×510; при увеличении на экранах высокой плотности пикселей детали могут выглядеть мягче, чем интерфейс. При финальной подготовке графики можно заменить эти четыре ресурса изображениями большего разрешения без изменения игровой логики.
