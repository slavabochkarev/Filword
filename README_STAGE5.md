# Филворд — этап 5: четыре размера и два способа ввода

Это продолжение Flutter-прототипа в `C:\Project\Filword`. Главного меню и сохранения прогресса пока нет. Миру соответствует размер: Неон-Сити 7×7, Космос 8×8, Биосфера 9×9, Киберядро 10×10. В финальной структуре запланировано по 100 уровней на мир; сейчас в приложении только по 5 тестовых уровней.

## Запуск и проверка

```powershell
cd C:\Project\Filword
flutter pub get
flutter run -d chrome
flutter devices
flutter run -d <android-device-id>
flutter test
flutter analyze
python -m unittest discover -s tests -v
python -m tools.validator_stage5 output_stage5/candidates.json
```

Повторить генерацию тестовой выборки:

```powershell
python -m tools.generate_stage5 --seed 20261009 --per-world 5 --attempts-per-level 12 --seconds-per-world 60
```

Генератор перезаписывает только `output_stage5/`. После намеренной перегенерации для обновления приложения нужно скопировать `output_stage5/candidates.json` в `assets/levels.json` и запустить Flutter-тесты. Данные и инструменты предыдущих этапов остаются доступными. `assets/levels_stage4.json` хранит прежние 10 тестовых полей 10×10 для проверки совместимости.

## Управление

- Проведение: удерживайте первую клетку и ведите по соседним клеткам; слово проверяется при отпускании.
- Нажатия: нажимайте на соседние клетки по очереди, затем «Проверить». «Сбросить» очищает только текущий выбор.
- Возврат на предпоследнюю клетку убирает последний шаг в обоих режимах.
- Уже найденные клетки доступны для новых слов. Позже найденный путь рисуется поверх раннего.
- Поле, счётчик и обе строки кнопок неподвижны; прокручивается только список слов.

## Результат эксперимента

`output_stage5/candidates.json` содержит 20 уровней с `gridSize` и каноническими путями. `output_stage5/report.json` фиксирует seed, ограничения и попытки. При seed 20261009 получено по 5 уровней для каждого мира, всего 240 попыток; структурный валидатор принял все 20. Диапазоны числа слов: 7×7 — 6; 8×8 — 8–9; 9×9 — 11–12; 10×10 — 13–15. Это тестовый контент без ручной редакторской оценки слов и сложности.

Скриншоты каждого размера находятся в `screenshots/stage5_*`. Автоматические тесты охватывают логику, оба способа ввода, геометрию на ширинах 360/390/412, неподвижность поля и обратную совместимость. Удобство реального пальца и поведение на конкретных Android-устройствах требуют ручной проверки: эмуляция касаний не измеряет ошибки человека.
