# Филворд — этап 3: любой путь к целевому слову

Результаты этапа 2 остаются в `output/`. Новая выборка, отчёты, PNG и интерактивная галерея находятся в `output_stage3/`. Flutter здесь нет; исходные проекты CrossSlow и «Пятибукв» не изменялись.

## Запуск

Из корня `C:\Project\Filword` (Python 3.11+, Pillow из `requirements.txt`):

```powershell
python -m unittest discover -s tests -v
python -m tools.generate_stage3 --seed 20261009 --per-world 20 --attempts-per-level 30 --seconds-per-world 45
python -m tools.validator_stage3 output_stage3/candidates.json --output output_stage3/validation.json
python -m tools.render_stage3
python -m tools.report_stage3
```

Откройте `output_stage3/gallery.html` как локальный HTML-файл. Выберите уровень и проведите мышью или пальцем по буквам. Кнопка «Показать альтернативный жест» демонстрирует заранее найденный допустимый путь, часто отличный от канонического. Голубой контур временно показывает выбранные клетки; постоянный цвет — записанный путь. «Показать последний жест» позволяет сравнить их повторно.

## Правила модели

`tools/gameplay.py` принимает список индексов 0–99. Допустимы только соседние клетки по восьми направлениям, без повторов внутри жеста. Любой путь, образующий ещё не найденное целевое слово, засчитывается. Результат содержит текст, корректность жеста, принадлежность целям, признак повтора, канонический путь подсветки и признак завершения уровня. Фактический путь не меняет каноническое покрытие 100 клеток.

`tools/validator_stage3.py` независимо проверяет покрытие, буквы, пути, тему, дубли и ограничение не более двух использований слова во всей выборке. Альтернативные пути выводятся как предупреждения, не как ошибки. `output_stage3/validation.json` содержит диагностику по всем 80 уровням.

## Пул и метод

От каждого мира берутся три характерных слова длиной 8–12 из ручного списка этапа 2. Остальное покрытие набирается словами длиной 6–7 из копии игрового словаря CrossSlow, пересечённой с копией списка sk4tzR и очищенной существующими исключениями. В общем пуле 1140 слов. Это экспериментальный пул, не окончательно утверждённый словарь. Полный Harrix не добавляется автоматически.

Генератор повторно использует укладку полного пути этапа 2. При выборе кандидата штрафуются повторы слов, избыток поворотов и длинный список слов. Альтернативные пути слегка ухудшают оценку, но не блокируют уровень. Seed и количество попыток задаются явно; предел времени защищает от зависания. При достижении предела времени результат может зависеть от скорости компьютера.

## Артефакты и ограничения

- `output_stage3/comparison.md` — сравнение двух экспериментов и оценка риска подсветки.
- `output_stage3/candidates.json` — 80 новых полей с путями и диагностикой.
- `output_stage3/gallery.html` и `gallery.js` — интерактивная галерея; `png/` — два PNG на уровень.
- `output_stage3/alternative_examples.json` — примеры альтернативных жестов для каждого уровня.
- `output_stage3/report.json` и `validation.json` — счётчики и результаты проверки.

Автоматические тесты проверяют Python-механику, генерацию и сохранённые уровни. JavaScript прошёл синтаксическую проверку Node.js. Реальную работу локальной HTML-галереи в браузере и удобство жестов на телефоне необходимо проверить вручную: автоматический браузер в этой среде блокирует открытие `file:` URL по политике безопасности. Примеры альтернатив намеренно выбираются с максимальным различием путей среди ограниченной выборки; это стресс-проверка, не оценка поведения игроков.
