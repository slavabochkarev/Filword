# ПоискСлов

Flutter-игра с поиском слов на полях 7×7, 8×8, 9×9 и 10×10. Репозиторий содержит **первую тестовую версию**: четыре визуальных мира и 20 уровней, по пять на мир. Планируемые 400 финальных уровней ещё не подготовлены.

## Запуск

Нужны Flutter SDK и настроенная среда Android или Web. Из корня проекта:

```powershell
flutter pub get
flutter run -d chrome
```

Для Android выполните `flutter devices`, затем `flutter run -d <device-id>`.

## Проверка и сборка

```powershell
flutter analyze
flutter test
python -m unittest discover -s tests -v
flutter build web
flutter build apk --debug
```

Результаты сборки создаются локально в `build/web` и `build/app/outputs/flutter-apk/app-debug.apk`. Сборки и кеши не входят в Git.

## Как устроен проект

| Каталог | Содержимое |
| --- | --- |
| `lib/` | Экраны Flutter, игровая сессия и локальное сохранение. |
| `assets/levels.json` | 20 готовых уровней, загружаемых приложением. |
| `assets/images/` | Ресурсы заставки, главного экрана и четырёх карточек. |
| `DOC/` | Исходные изображения дизайна. |
| `data/`, `tools/`, `tests/` | Словари, Python-генератор и его тесты. |
| `output*`, `screenshots/` | Результаты экспериментов и снимки интерфейса. |

Игра принимает любой непрерывный путь, который образует целевое слово, и подсвечивает фактически выбранные клетки. Проведение пальцем/мышью и последовательные нажатия работают одновременно. Игровое поле не прокручивается.

Прогресс завершённых уровней и тема сохраняются локально. Найденные слова незавершённого уровня пока не восстанавливаются после перезапуска. Все четыре мира доступны в тестовой версии; статистика и достижения отражают реальные завершённые уровни.
