# Филворд — проверочный генератор

Только Python-инструменты и экспериментальные данные. Flutter-приложение отсутствует. CrossSlow и «Пятибукв» не изменяются.

## Запуск

Из корня проекта (Python 3.11+; для PNG нужен Pillow):

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m tools.lexicon
python -m tools.generate --seed 20261009 --per-world 20 --attempts-per-level 500 --seconds-per-world 60
python -m tools.validator output/candidates.json --output output/validation.json
python -m tools.render
python -m tools.report
```

Откройте `output/gallery.html`. Файлы `png/*_A.png` показывают поле игрока, `*_B.png` — проверочную схему. `output/candidates.json` содержит полные уровни, `output/report.json` и `output/validation.json` — метрики и дефекты, `output/summary.md` — краткий вывод.

Генератор детерминирован по seed, входным данным и числу попыток. Ограничение времени служит аварийной границей: при его достижении число результатов зависит от скорости компьютера. Для точного повторения используйте достаточно высокий лимит времени и фиксированное число попыток.

## Словари

`data/source/` — неизменённые снимки из CrossSlow: игровой словарь, Harrix, sk4tzR, исключения и предварительные пометки. `data/themes/` — ручные короткие тематические списки. `tools.lexicon` принимает из них только слова длиной 3–12 с допустимыми буквами, встречающиеся в CrossSlow или Harrix, применяет запреты и сохраняет источник каждого слова в `data/experimental_lexicon.json`. Отчёт о количестве и отклонениях — `data/lexicon_report.json`. Эти слова **не утверждены редактором**. Полный Harrix не попадает в игровой набор.

Нормализация: `Ё → Е`; `Й` сохраняется. Сокращения, дефисы, пробелы внутри слова, цифры и латиница отклоняются. Лицензии исходных списков скопированы в `data/licenses/` и должны сопровождать дальнейшее использование этих данных.

## Алгоритм

Сумма длин выбранных слов равна 100. Полный самонепересекающийся путь по полю 10×10 получается из построчной змейки и рандомизируется обратимыми перестановками отрезков, сохраняющими соседство. Отрезки назначаются словам, поэтому покрытие гарантировано конструкцией. Валидатор независимо проверяет координаты, буквы, покрытие, пересечения, тему, дубли и альтернативные пути слов. Генератор ограничен числом попыток на уровень и временем на мир.

Сохранённый кандидат `strict_pass` прошёл автоматические проверки, включая отсутствие найденных альтернативных путей к целям. `review_rejected` оставлен в галерее для анализа причин; он **не является игровым уровнем**. Ни один кандидат не считается окончательно утверждённым до ручной тематической и визуальной проверки. Уровни имеют 20 экспериментальных ID в каждом диапазоне мира: 1–20, 101–120, 201–220, 301–320.

## Ограничения эксперимента

Тематические списки невелики и требуют расширения и редактуры. Подсчёт альтернативных путей ограничен 20 на слово; при достижении лимита отчёт помечает результат как усечённый. Подсчёт сложности — временная эвристика, а не калиброванная шкала. Случайные дополнительные слова, не являющиеся целями, ещё не оцениваются исчерпывающе. PNG показывают читаемость на заданном размере изображения, но не заменяют проверку жестов на смартфоне.
