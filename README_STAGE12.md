# ПоискСлов — этап развития игры

## Состав

В `assets/levels.json` находятся 80 уровней: по 20 для Города (7×7), Космоса (8×8), Природы (9×9) и Науки (10×10). Первые пять уровней каждого мира перенесены без изменения. Их исходная копия сохранена в `output_stage12/original_levels.json`. Для новых уровней применён существующий генератор геометрии из `tools/generate_stage5.py`; ограниченный пакетный запуск оформлен в `tools/generate_levels.py`. Независимый структурный валидатор — `tools/validator_stage5.py`.

Генератор использует фиксированный seed `20261010`, максимум 40 попыток на слот и 90 секунд на мир. Он проверяет покрытие, непрерывность, буквы, пересечения, дубли сеток и наборов слов, ограничивает повтор слова двумя уровнями и исключает пары целевых слов, где одно является началом другого. Пример запуска для исходного 20-уровневого набора:

```powershell
python -m tools.generate_levels --project C:\Project\Filword --original C:\Project\Filword\output_stage12\original_levels.json --output C:\Project\Filword\output_stage12\regenerated
```

Команда использует сохранённые исходные 20 уровней, а результат кладёт в отдельную папку. Для проверки готового файла:

```powershell
python -m tools.validator_stage5 assets/levels.json
python -m unittest discover -s tests
flutter analyze
flutter test
flutter build web
flutter build apk --debug
```

## Результат генерации

| Мир | Размер | Старых | Новых | Попыток | Среднее число поворотов: старые → новые |
|---|---:|---:|---:|---:|---:|
| Город | 7×7 | 5 | 15 | 600 | 21 → 29,2 |
| Космос | 8×8 | 5 | 15 | 600 | 24,8 → 35,13 |
| Природа | 9×9 | 5 | 15 | 600 | 26,2 → 32,33 |
| Наука | 10×10 | 5 | 15 | 600 | 28,2 → 33,53 |

Валидатор принял 80/80. Всего 710 уникальных слов: 628 встречаются один раз, 82 — два раза. Среднее количество слов на уровне — 9,9. Распределение длин: 6 — 288; 7 — 264; 8 — 57; 9 — 58; 10 — 66; 11 — 42; 12 — 17. Подробности — `output_stage12/report.json`.

Каждый уровень содержит три проверенных по экспериментальному тематическому списку длинных слова. Остальные слова взяты из пересечения игрового словаря CrossSlow и списка общеупотребительных существительных с прежними исключениями. Это структурно корректный набор, **но его тематическая и редакторская оценка ещё нужна**: в некоторых уровнях нейтральные слова заметно расходятся с темой мира. Такой уровень не следует считать окончательно утверждённым контентом.

## Прогресс и миграция

Состояние хранится локально в одном JSON-снимке SharedPreferences под ключом `poiskSlov.progress.v2`. В нём отдельно записаны исторические суммы и текущее прохождение каждого мира: текущий индекс, завершённые круги, активное время всего и текущего круга, время последнего и лучшего полного круга, найденные пути, купленные подсказки. Отдельно хранятся баланс и суммы кристаллов, идентификаторы операций и даты достижений. Настройки темы и эффектов используют прежние ключи.

При первом запуске новой версии старые `completedIds`, статистика и настройки переносятся. Прежние пять уровней мира становятся прогрессом 5/20, а не завершённым кругом. Неизвестное время старых прохождений остаётся неизвестным. Стартовые 100 кристаллов выдаются один раз; награды за старые уровни задним числом не начисляются. Старый прототип не сохранял найденные слова незавершённого уровня, поэтому перенести их невозможно.

Активный таймер запускается при появлении поля и останавливается при паузе, уходе приложения в фон, выходе с экрана и завершении уровня. Накопленные секунды сохраняются по каждому миру. После двадцатого уровня фиксируется время круга и открывается новый круг с первого уровня без удаления истории.

## Экономика и подсказки

- Первый запуск: 100 кристаллов.
- Первое завершение уровня: 10; повторное: 2.
- Завершение мира: 50 за каждый круг.
- «Показать начало пути»: 20; «Открыть слово»: 30.

Подсказки покупаются для выбранной скрытой строки. Купленный вариант остаётся доступным бесплатно в текущем уровне. Начало показывает старт канонического допустимого пути, но фактический путь игрока по-прежнему может отличаться. Полный ответ не засчитывает слово. Списание, состояние подсказки и идентификатор операции входят в один сохраняемый снимок. Рекламного SDK и имитации рекламы нет; для будущей интеграции добавлен интерфейс `lib/rewarded_ad_service.dart`.

Список слов скрывает ответы на каждом круге; найденные слова раскрываются и зачёркиваются. Сохраняется фактически выбранный путь. Игровое ядро, размеры полей, два способа ввода, экран загрузки, карусель и эффекты победы не изменялись.

## Оставшиеся ограничения

1. Тематическую уместность и качество русских слов нужно проверить редактору до публикации уровня как окончательного.
2. Рекламные награды пока не подключены; интерфейс сервиса подготовлен, кнопки рекламы нет.
3. Управление Android и Web покрыто widget-тестами и сборками. Практическую эргономику на реальном телефоне с новым списком скрытых слов ещё нужно оценить вручную.
4. Опубликованную на `bochk.ru` политику конфиденциальности нужно сверить с новым составом локально хранимого прогресса перед публичным релизом.
